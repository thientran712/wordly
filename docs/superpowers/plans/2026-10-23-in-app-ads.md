# Quảng cáo trong app (AdMob) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App iOS Wordly hiện 4 loại quảng cáo AdMob, giới hạn 10 lượt dịch/ngày mở thêm bằng quảng cáo đổi thưởng (+10 lượt cộng dồn), theme widget đặc biệt mở khoá bằng quảng cáo — bật/tắt từ server.

**Architecture:** Server (Next.js `web/`) đếm lượt dịch trong Postgres bằng hàm `SECURITY DEFINER` (giống `consume_quota` của Pro), cộng thưởng chỉ khi callback SSV của Google có chữ ký hợp lệ, trả cấu hình quảng cáo qua `/api/app-config`. App iOS bọc Google Mobile Ads SDK trong `AdsManager` mỏng; mọi quyết định "có hiện không" là logic thuần trong `AdsLogic.swift` để test được.

**Tech Stack:** Next.js 16 route handlers, Supabase Postgres (migration SQL), `node:test`, Node `crypto` (ECDSA P-256); SwiftUI iOS 17, XcodeGen, Google Mobile Ads SDK (SPM `swift-package-manager-google-mobile-ads`) + UMP, XCTest.

**Spec:** `docs/superpowers/specs/2026-10-23-in-app-ads-design.md` — đọc trước, mọi con số lấy từ đó.

### Task 4: Callback SSV của AdMob

**Files:**

**Interfaces:**
- Produces:
  - `verifySsvSignature(rawQuery: string, keys: Array<{keyId: number, pem: string}>) → boolean` — nội dung ký = phần query trước `&signature=`; `signature` base64url (DER), `key_id` chọn khoá; ECDSA P-256 / SHA-256 qua `crypto.verify`.
  - `parseReward(params: URLSearchParams) → { transactionId, userId, kind: 'translate'|'theme', themeId: string|null } | null` — `user_id` phải UUID; `custom_data` = `translate` hoặc `theme:<id>` với id `^[a-z0-9_-]{1,64}$`; thiếu `transaction_id` → null.
  - `fetchVerifierKeys()` — GET `https://www.gstatic.com/admob/reward/verifier-keys.json`, cache trong RAM 24 giờ; key lạ → tải lại một lần.
  - Route GET: query không parse được hoặc chữ ký sai → 400; hợp lệ → `admin.rpc("grant_ad_reward", { p_transaction_id, p_user_id, p_kind, p_theme_id, p_credits: adsConfig().rewardCredits })` → 200 cả khi `'duplicate'`; DB lỗi → 500 (Google sẽ gọi lại).
